## About Me

I'm a Software Development Engineer at **Standard Chartered**, with an Integrated M.Sc. in Applied Mathematics from **IIT Roorkee**.

My work lies at the intersection of **software engineering, artificial intelligence, distributed systems, and quantitative problem-solving**.

I enjoy designing systems that go beyond basic application development — from high-throughput backend services and data-intensive pipelines to intelligent agents capable of reasoning, analyzing information, and executing multi-step workflows.

My engineering interests include:

- **Backend & Distributed Systems:** Scalable services, API design, asynchronous processing, database engineering and system architecture.
- **AI & LLM Engineering:** Agentic workflows, LLM applications, AI automation, RAG and intelligent systems.
- **Data Engineering:** ETL pipelines, large-scale data processing, transaction reconciliation and analytics.
- **Applied Mathematics:** Numerical methods, mathematical modelling, machine learning and optimization.
- **Algorithms:** Competitive programming, advanced data structures, graph algorithms and problem-solving.
